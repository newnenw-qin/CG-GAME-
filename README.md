# Qin Ziwen — Enter the Unknown

这是一个 **Next.js** 个人作品集，不是普通的静态 HTML 文件夹。

把代码放到 GitHub **不会自动变成可打开的网站**。需要在本地运行，或部署到 GitHub Pages / Vercel。

## 本地运行

需要先安装 [Node.js 18+](https://nodejs.org/)。

```bash
npm install
npm run dev
```

浏览器打开：

http://localhost:3000

## 部署成在线网站

### 方式一：Vercel（最稳）

1. 打开 [vercel.com](https://vercel.com)
2. Import 这个 GitHub 仓库
3. 保持默认设置，Deploy

几分钟后会得到一个可分享的网址。

### 方式二：GitHub Pages

1. 把完整项目推送到 `main` 分支
2. 打开仓库 **Settings → Pages**
3. Build and deployment → Source 选 **GitHub Actions**
4. 等待 Actions 跑完

网站地址：

https://newnenw-qin.github.io/CG-GAME-/

如果仓库是 **Private**，GitHub Pages 可能无法公开访问，请改用 Vercel，或把仓库设为 Public。
